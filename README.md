# TruequeUni - Plataforma de donación e intercambio universitario

TruequeUni es una aplicación web de tipo *software horizontal* diseñada para la comunidad estudiantil de la Universidad Autónoma de Manizales (UAM). Su principal objetivo principal es facilitar el intercambio o donación de ropa, materiales acádemicos en buen estado ambas cosas. Priorizando a estudiantes en condiciones de vulnerabilidad ecónomica. 

## Tecnologías Utilizadas

Este proyecto utilizó: 
**Frontend:** HTML, CSS. 
**Bases de Datos:** MySQL. 
**Backend:** Java. 
**Gestión del proyecto:** Jira (Metodología Scrum).
**Control de versiones:** GitHub. 

## Estructura del Repositorio

El proyecto está organizado en las siguientes carpetas principales: 
`/frontend`: Contiene las vistas de la página web que son los archivos de maquetación. (HTML, CSS). 
`/backend`: Código fuente, en el cual se implementan las funcionalidades de la página Web, contiene los modelos, controladores, Lógica de negocio. 
`/database`: Scripts SQL (DDL para la creación de la tablas que guradan los datos solicitaos en el sistema y DML para los datos de prueba).
`/docs`: Documentación del proyecto (Todo lo solicitado en el informe, parte 1 y 2, diagramas, mockups).
